> Design, simulation, and physical build of a 4-to-1 multiplexer from combinational logic.

## Overview
A 4-to-1 multiplexer routes one of four data inputs to a single output based on two select lines. This project takes the design end to end: constructing the truth table, deriving and simplifying the Boolean expression through a Karnaugh map, drawing the gate-level schematic, simulating the circuit, and verifying the data-routing and select behavior on a physical PCB build.

## Highlights
- Full combinational logic workflow: truth-table construction, Boolean-expression derivation, K-map simplification, and gate-level schematic.
- Two select lines addressing four data inputs through the simplified sum-of-products logic.
- Circuit simulation to validate the logic before committing to hardware.
- PCB-based physical implementation with hands-on experimental verification.

## Key Results
- Simulated output matched the multiplexer truth table across all input and select combinations.
- The physical PCB build reproduced the expected data-routing and select behavior, confirming the simulation.
