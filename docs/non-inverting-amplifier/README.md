# Non Inverting Amplifier

> Modeling, LTspice simulation, and PCB realization of a non inverting operational amplifier circuit.

## Overview
This lab models, simulates, and physically builds a non inverting operational amplifier circuit. It applies ideal op amp theory (the virtual short and a closed loop gain of 1 + Rf/R) to predict the behavior, validates it with an LTspice XVII transient simulation that uses an OP07 model and a potentiometer as the feedback resistor, and realizes the design in hardware through a Proteus PCB layout.

## Highlights
- Grounded in ideal op amp theory, using the virtual short and a closed loop gain of 1 + Rf/R.
- LTspice XVII transient simulation with a real OP07 op amp model.
- A potentiometer as the feedback resistor, which makes the gain adjustable.
- A Proteus PCB layout carried through to a final physical product.

## Key Results
- The simulated output matched the predicted closed loop gain, confirming the non inverting configuration.
- The hardware build reproduced the amplified output waveform, in phase with the input, that the theory predicts.
