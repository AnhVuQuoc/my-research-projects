> Design, simulation, and physical build of a 4-to-1 multiplexer from combinational logic.

## Overview
A 4-to-1 multiplexer routes one of four data inputs to a single output, based on two select lines. This project takes the design from start to finish. It constructs the truth table, derives and simplifies the Boolean expression with a Karnaugh map, draws the schematic at the gate level, simulates the circuit, and verifies the data routing and select behavior on a physical PCB build.

## Highlights
- A complete combinational logic workflow, from the truth table to the Boolean expression, its K-map simplification, and the gate level schematic.
- Two select lines address four data inputs through the simplified sum-of-products logic.
- Circuit simulation validates the logic before the design is committed to hardware.
- A physical implementation on a PCB, verified through hands on experiments.

## Key Results
- The simulated output matched the multiplexer truth table for all input and select combinations.
- The physical PCB build reproduced the expected data routing and select behavior, confirming the simulation.
