## Overview
This lab models, simulates, and physically builds a non-inverting operational-amplifier circuit. It applies ideal op-amp theory (virtual short, closed-loop gain = 1 + Rf/R) to predict behaviour, validates it with an LTspice XVII transient simulation using an OP07 model and a potentiometer-based feedback resistor, and realizes the design in hardware via a Proteus PCB layout.

## Highlights
- Grounded in ideal op-amp theory: virtual short and closed-loop gain of 1 + Rf/R.
- LTspice XVII transient simulation using a real OP07 op-amp model.
- Potentiometer-based feedback resistor for adjustable, tunable gain.
- Proteus PCB layout carried through to a final physical product.

## Key Results
- Simulated output matched the predicted closed-loop gain, confirming the non-inverting configuration.
- Hardware build reproduced the amplified, in-phase output waveform expected from the theory.
